# Source attribution

The compiler and single-GPU runtime come from commit
`9bb7b3343217fc8d3db2eb2de4e8e3b0eeb50b3c` of Megakernel Lab.
Latch v0 supplies the supported examples and omits experimental
distributed execution. Its executable compiler code, examples, numerical policies and dependencies
match the smoke-tested candidate. The package version is now 0.0.0; public
branding, documentation and licensing were updated for Latch v0.

[Third-party notices](THIRD_PARTY_NOTICES.md) identify adapted upstream code.
Original copyright notices and licenses remain beside the code and under
`provenance/upstream/`. Historical checkout names there identify sources;
they are not runtime dependencies.

Research reports and older qualification records are retained in the private
research archive. The public documentation focuses on using the package.
