Get started

Compile a small training program, run its generated update, then change the model and compile again.

Source archive with examples and docs · Installable wheel · SHA-256 checksums

Requirements

The tested environment is Linux, Python 3.12, PyTorch 2.9.1 with CUDA 12.8 and an NVIDIA H100 80 GB. Compilation also needs the CUDA 12.8 development toolkit (nvcc, nvlink, cuobjdump), a host C++ compiler and Python headers. See environment setup.

Install

Download the archive and wheel into the same directory, then:

tar -xzf latch-v0.tar.gz
cd latch-v0
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch==2.9.1 \
  --index-url https://download.pytorch.org/whl/cu128
python -m pip install '../megakernel_lab-0.0.0-py3-none-any.whl[gpu]'

The archive supplies the examples and docs. The wheel supplies the compiler; generated GPU programs are built in the next step.

Compile and run training code

This small MLP uses synthetic data, so no model or corpus download is needed. From the unpacked archive:

export LATCH_ROOT="$PWD/latch-output"
CUDA_VISIBLE_DEVICES= python examples/quickstart.py prepare \
  "$LATCH_ROOT/mlp" --cache-dir "$LATCH_ROOT/cache"
python examples/quickstart.py run "$LATCH_ROOT/mlp" --steps 10

The first command captures and compiles the supported training program on CPU. The second runs ten changing updates on H100. Keep the output and cache directories at the same absolute paths if building and running on different hosts.

Change a model or learning setting

Double the hidden width and change the learning rate, then compile a separate program:

CUDA_VISIBLE_DEVICES= python examples/quickstart.py prepare \
  "$LATCH_ROOT/mlp-wide" --cache-dir "$LATCH_ROOT/cache" \
  --hidden 128 --lr 0.0005
python examples/quickstart.py run "$LATCH_ROOT/mlp-wide" --steps 10

The example source shows the model and compiler API. Supported changes generate a new program; arbitrary PyTorch code is not supported.

Try it with a coding agent

Read README.md and examples/quickstart.py. Run the MLP example,
then double its hidden width and compare both generated programs.
Compile on CPU, run on H100, and report any unsupported operations.

Included examples

  • TinyMoE: prepare public model/data, compile a complete update and run 32 updates.
  • Selective updates: update shared weights and experts at different rates.
  • SMELT-style looped TinyMoE: repeat layers with shared weights and accumulated gradients.
  • GradLev: adapt GPT-2’s final MLP token by token.
  • Fast examples: smaller supported model and learning families with conventional controls.

Install optional dependencies from the same downloaded wheel:

python -m pip install '../megakernel_lab-0.0.0-py3-none-any.whl[tinymoe]'
python -m pip install '../megakernel_lab-0.0.0-py3-none-any.whl[gradlev]'
